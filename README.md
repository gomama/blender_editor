# VRM Head Swapper (VRM 頭部入れ替えエディタ)

Webブラウザ上でVRMアバターの「編集済みの頭部（顔・髪・表情）」と「ベースモデルの体」を手軽に入れ替えて合成・エクスポートできるツールです。

## 主な機能
- **ドラッグ＆ドロップで手軽に読み込み**:
  - ベースモデル（体を提供するVRM）
  - 頭部モデル（編集済みの顔・髪を提供するVRM）
- **自動パーツ検出 & カスタマイズ**:
  - 顔・髪・衣装のメッシュパーツを自動検出。手動でチェックボックスによる選択・除外も可能。
- **表情・マテリアル・テクスチャの完全保持**:
  - 表情（BlendShape / Expressions）、髪などのマテリアルやテクスチャを壊さずに安全に移行。
- **位置合わせスライダー**:
  - 首の高さ（Y軸）や前後の位置（Z軸）の微調整が可能。
- **3Dリアルタイムプレビュー & 表情テスト**:
  - Three.js + `@pixiv/three-vrm` による合体結果の3Dプレビュー。
  - まばたきや笑顔、口の動き（母音）などのテストが可能。
- **ワンクリックダウンロード**:
  - 合成したアバターを新しい `.vrm` ファイルとして保存。

## 起動方法

```bash
# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで表示されるローカルURL（例: `http://localhost:5173`）を開いてご利用ください。

## コマンド
- `npm run dev`: ローカル開発サーバー起動
- `npm run lint`: コードの静的検査 (ESLint)
- `npm test`: 単体テスト実行 (Vitest)
- `npm run build`: プロダクション用ビルド
